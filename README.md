# Netflix Data Analysis with  Dashboard

## Overview
This project focuses on analyzing Netflix recommendation data using Python and data visualization techniques.

The analysis explores:
- Most popular genres
- Highest rated genres
- Ratings distribution
- Top rated movies

A dashboard-style visualization was created using Matplotlib to present insights in a more interactive and visually appealing format.

---

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

---

## Dataset
The dataset contains Netflix movie recommendation information including:
- Movie names
- Genres
- Ratings

## Key Insights
- Sci-Fi and Action are among the most popular genres
- Animation received some of the highest average ratings
- Ratings are concentrated around mid-to-high score ranges
- Certain movies consistently received higher audience ratings
